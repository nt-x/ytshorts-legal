Privacy Policy

Last updated: 14 October 2026

YTShortsGen ("the application") is a private tool operated by a single creator to upload videos to YouTube channels that the operator owns. This policy explains what data the application accesses and how it is handled.

YouTube API Services

The application uses YouTube API Services. By using it you are also bound by the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy.

Data accessed

  • An OAuth access and refresh token for the operator's own YouTube channels, granted via Google sign-in.
  • Basic channel information (channel ID and title) needed to choose the upload destination.
  • Metadata of videos the application uploads (video ID, upload status), used to track its own uploads.

The application does not access, collect or store data about any other YouTube users or viewers.

How data is used and stored

Tokens and upload records are stored only on the operator's private server and are used solely to upload and manage the operator's own videos. No data is sold, shared with third parties, or used for advertising.

Revoking access

Access can be revoked at any time through the Google security settings page. Stored tokens are deleted when access is revoked or the application is decommissioned.
